# Curated surrogate results

These files aggregate three independent training seeds for Current MLP,
Window MLP, Data TCN, and PI-TCN.

- `surrogate_metrics_all_seeds.csv`: one-step, rollout, OOD physical, and
  monotonicity metrics.
- `rollout_by_horizon_all_seeds.csv`: WIP rollout error by prediction horizon.
- `summary.json`: aggregated effect sizes and mean metrics.
- `temporal_physics_evidence.png`: paper-ready temporal and physics evidence.
